# 🎉 Aplikasi Undian Arisan Citimall - PWA

Aplikasi undian arisan berbasis web yang ringan, cepat, dan bisa di-install di HP seperti aplikasi native. Dibuat untuk mempermudah pengundian arisan secara adil dan transparan.



### ✨ Fitur
- 🎲 Undian acak & transparan
- 📱 Bisa di-install di HP (PWA)
- 📴 Bisa offline
- 👥 Kelola anggota arisan
- 📜 Riwayat pemenang
- 🚀 Tanpa database, 100% berjalan di browser

### 📲 Cara Install di HP
1. Buka link aplikasi di Chrome
2. Klik titik tiga di pojok kanan atas
3. Pilih **"Tambahkan ke Layar Utama" / "Install App"**
4. Aplikasi akan muncul di home screen kamu

### 🛠️ Cara Pakai
1. Clone atau download repo ini
2. Buka file `index.html` di browser
3. Selesai!
